# nutriolera — передача проекта в облачную сессию

Лендинг и встроенный тест «Оценка рисков кариеса» для нутрициолога Валерии Кухарь (бренд **nutriolera**).
Прод: **https://nutriolera.vercel.app** (Vercel, проект `nutriolera`, аккаунт `thatmisusing-1139`).
Общение с заказчиком — по-русски.

## Как устроено

- **Один файл.** Внешние загрузки только шрифты: Google Fonts — Manrope (текст), Caveat (рукописные пометки), M PLUS Rounded 1c (только логотип, `&text=nutriolera`), Material Symbols Rounded (`north_east` в кнопках).
- **Тест** — оверлей `#test` в том же `index.html`. Открывается любой ссылкой `href="#test"`. Оплаты пока нет: кнопка сразу открывает тест. Прогресс и календарь хранятся в `localStorage` (`nutriolera-test-v1`).
- **Данные теста в JS:** `Q` — вопросы `[зона, текст, [[вариант, балл|null]]]`, зона `'med'` — флаг, `'open'` — открытые 46–50. `EMO` — эмодзи вариантов. `STEPS` — 3 шага по каждой зоне, `KEEP` — если все зоны зелёные. `MENU` — меню на 3 дня. `DAILY`/`WEEKLY`/`ONCE` — календарь гигиены.
- **Расчёт:** % зоны = баллы ÷ максимум зоны (максимум считается из `Q`): Питание 29, Напитки 12, Слюна 12, Гигиена 27, Образ жизни 21, Зубы 21. Каждая зона — своя шкала 0–100%, в сумме не 100 (заказчик спрашивал; объяснено, оставили). Основная зона — максимальная >25%, дополнительная — вторая >25%.
- **Цвета зон** (`ZC`): питание `#2fb67c`, напитки `#fb8c3c`, слюна `#2597d0`, гигиена `#c23a9b`, образ жизни `#f2c230`, зубы `#ea4f5a`. Эмодзи зон (`ZE`): 🥦 ☕ 💧 🪥 😴 🦷. Уровень (зелёный/жёлтый/оранжевый/красный) — плашкой у полосок, не цветом лепестка.
- **Диаграмма** — функция `rose()`: лепестки по `sqrt(%)`, основная зона выдвинута, подписи — эмодзи + название, крупный % под ними (на телефоне без названий).
- **Google-таблица:** `var SHEET_URL = ''` вверху скрипта. Пока пусто — ответы никуда не уходят.
- **PDF** — `window.print()` с print-стилями. Календарь на отдельной странице.

## Решения заказчика (не менять без спроса)

- Концепция «небо»: голубой градиент в первом экране, фото автора справа в рамке-полароиде, текст слева.
- Заголовок: «Пломбы меняются, а причина кариеса остаётся», под «остаётся» — линия цветов шкалы.
- Главная кнопка: «Получить оценку рисков кариеса», без цены. Цена 2 500 ₽ — только в блоке оплаты.
- Кнопки — синий градиент, справа стрелка `north_east` (вес 400, без круга, без анимации иконки), блик по кнопке остаётся.
- Эмодзи — системные символы (стиль Apple на iOS/Mac), не картинки.
- Все `h2` по центру, кроме блока цены на десктопе (там две колонки, слева).
- Синий градиент на ключевых словах части заголовков (`.gw`).
- В результате нет слова «риск», есть «зоны внимания» и «выраженность» + дисклеймер «не диагноз».
- Бонус — календарь гигиены на 4 недели (отмечать на сайте или распечатать).
- Стаж «N лет в нутрициологии» считается автоматически от 2017.
- Заказчик часто присылает правки пачкой: «пока не делай» → собрать список с номерами → «делай».

## Открытые вопросы

1. **Оплата** — сервис не выбран (Продамус / ЮKassa / Robokassa / Т-Банк / GetCourse). Нужен переход «оплата → закрытая страница с тестом».
2. **Google-таблица** — заказчик настраивает `google-sheets.gs`, присылает URL → вставить в `SHEET_URL` → задеплоить.
3. **Видео** — заглушка, ждём mp4 (класть в `site/`, без внешних плееров).
4. **Оферта и политика** — ссылки в подвале пустые (`href="#"`).
5. **Дедлайн** из гайда — реальной даты повышения цены нет, вместо него «мест в потоке ограничено».
6. **Тексты, которые писал ИИ**, нужно проверить заказчику: шаги (`STEPS`), меню (`MENU`), календарь. Шкалу вопроса 13 (кофе и чай: 0/1/2/3) в Excel просили подтвердить.
7. **Фото меню**: гречка (2-1) — сухая крупа, салат с тунцом (3-3) — салат с яйцом. Лучше заменить фото заказчика.
8. Пояснение под диаграммой «проценты не складываются» — предложено, ответа нет.
