# Landly Studio

Здесь делают лендинги напрямую в чате — с той же «подкапотной» частью, что у агента
Landly: правилами вёрстки, справочниками, библиотекой анимаций, стилями, фото со
стоков, скриншотами и проверками. Отвечай пользователю по-русски.

Справочники — ссылки на репозиторий Landly, поэтому всегда актуальны:

| Путь | Что там |
|---|---|
| `guides/hero.md` | первый экран: архетипы, анти-шаблон, обязательный живой элемент |
| `guides/blocks.md` | приёмы блоков с сильных продуктовых сайтов (Refero) |
| `guides/fonts.md` | шрифты с кириллицей и как их подключать |
| `guides/procedural.md` | процедурная графика: пряди, потоки, рельеф — рецепты с кодом |
| `guides/art-director.md` | чек-лист раунда арт-директора |
| `guides/icons.md` | как искать иконки в `library/icons` и какой набор под какой тон |
| `guides/prompt-spec.md` | как писать сильную спецификацию страницы и где подсматривать идеи |

## Как работаем над сайтом

1. **Бриф.** Пользователь описывает продукт, может приложить файлы и ссылки.
2. **Короткий бриф — допиши до спецификации** по guides/prompt-spec.md и покажи
   пользователю: концепция, палитра, шрифты, секции. Факты не выдумывай.
3. **Направление дизайна.** Задай 3–4 коротких вопроса: референсы, тон, обязательные
   факты (цены, адреса, цифры), что точно не нравится. Если бриф уже отвечает —
   не спрашивай лишнего.
4. **Концепции.** Предложи 2–3 концепции по одной строке: образ первого экрана,
   палитра, шрифты, характер. Жди выбора пользователя.
5. **Вёрстка.** Используй скилл frontend-design. Прочитай guides/hero.md,
   guides/blocks.md, guides/fonts.md, guides/procedural.md, guides/icons.md,
   guides/anatomy.md и, если нужны анимации или готовые элементы,
   effects/landly-fx.md и library/ui/INDEX.md. Сайт — в `sites/<латинское-имя>/index.html`.
6. **Фото, если нужны:** `npm run photos -- sites/<имя> "english query" 4`.
7. **Скриншоты и проверки:** `npm run shot -- sites/<имя>`. Посмотри
   `shots/desktop-hero.png`, `shots/desktop.png`, `shots/mobile.png`.
8. **Раунд арт-директора** по guides/art-director.md: 3–6 весомых улучшений,
   снова скриншоты. Покажи пользователю результат и спроси, что поправить.

## Правила вёрстки (как у агента Landly)

- Один сайт — одна страница: один `index.html`, CSS и JS встроены в него.
  Многостраничный сайт — блоками на одной странице с навигацией по якорям.
- Внешние загрузки запрещены, **кроме шрифтов** с Google Fonts, Fontshare, Bunny Fonts
  по https. Всегда системный запас в `font-family`. Для русского текста — только
  шрифты с кириллицей.
- Изображения: инлайновый SVG, CSS, процедурная графика скриптом на странице или
  файлы из `photos/` рядом со страницей.
- Шейдеры, глобус и движки: скопируй нужный файл в папку сайта
  (`effects/landly-shaders.js`, `effects/landly-globe.js`,
  `library/runtime/anime.min.js` или `motion.min.js`) и подключи его
  `<script src="…" defer></script>`. Движок — не больше одного на страницу.
- `<!DOCTYPE html>`, `lang`, `<meta name="viewport" …>`; на ширине 375 px без
  горизонтальной прокрутки; файл до 400 КБ.
- Иконки — из `library/icons` (Grep по названию, см. guides/icons.md), один набор
  на страницу, не на каждом заголовке. Вручную не рисуй.
- Типографика: неразрывный пробел после коротких предлогов и союзов (в, к, с, у, о,
  а, и, но, из, до, по, от, для, что, как) там, где строка может перенестись;
  без ручных `<br>`, если вёрстка и так не ломается.
- В первом экране — один главный живой элемент: процедурная графика или эффект
  из библиотеки. Остальные эффекты — только там, где они что-то значат.
- Референсы — источник идей, не копия: не переноси тексты, логотипы, фотографии
  и структуру чужих сайтов один в один. Бренды в примерах — вымышленные.
- Не выдумывай факты о продукте: цены, гарантии, «без логов» — только из брифа.
