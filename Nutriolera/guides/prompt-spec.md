# Спецификация страницы: как выглядит сильный бриф

«Сделай красиво и премиально» даёт одинаковый ИИ-сайт. Сильные страницы
получаются из подробной спецификации: концепция, точные цвета, шрифты,
порядок секций, движение и картинки названы заранее. Этот формат Landly
использует, когда дописывает короткий бриф клиента, и его же удобно писать
вручную в Studio.

Составлено по разбору открытых библиотек промптов для сайтов (Meez,
WebsitePrompts, 21st.dev и других): сами промпты не копируются, взят формат.

## Разделы спецификации

1. **Суть.** Что за продукт, для кого, одно главное действие посетителя.
   Факты — только из брифа: цены, адреса, телефоны, цифры, отзывы, имена.
2. **Концепция.** Одна фраза-образ: из какого мира страница, какой у неё
   характер. Не «современный минимализм», а «меню уличной шаурмы, набранное
   как афиша бокс-вечера».
3. **Палитра.** 4–6 цветов hex с ролями: фон, текст, поверхность, акцент,
   второстепенный. Где живёт акцент (только кнопки, только цифры).
4. **Шрифты.** 1–2 гарнитуры с кириллицей (guides/fonts.md), начертания,
   кегль заголовка первого экрана, трекинг. Роль каждой.
5. **Первый экран.** Архетип из guides/hero.md, главный живой элемент,
   что крупно, где кнопка. Одна строка — чем экран запомнится.
6. **Секции по порядку.** Для каждой: задача, раскладка (сетка, список,
   таблица, крупная цифра, фото на всю ширину), что внутри. 6–10 секций,
   соседние — разной раскладкой.
7. **Движение.** Один громкий эффект (в первом экране), 1–2 тихих отклика.
   По id из effects.md, если доступна библиотека «Про».
8. **Изображения и иконки.** Фото (какие сюжеты), процедурная графика
   (что генерирует скрипт), набор иконок из guides/icons.md.
9. **Тон текстов.** Как говорит бренд: 2–3 признака и пример фразы.
10. **Чего не делать.** 3–5 запретов под этот бриф: какие клише ниши,
    какие цвета, какие приёмы.

## Правила

- Конкретика вместо прилагательных: не «премиальный шрифт», а «Prata 400,
  64px, трекинг −1%».
- Всё выбирается из предмета брифа: материалы, профессиональный язык,
  предметы этой сферы.
- Не выдумывать факты. Если для блока нужны цифры или отзывы, которых нет,
  блок описывается без них или не ставится.
- Спецификация — ориентир, а не клетка: хорошая находка при вёрстке важнее
  пункта спецификации.

## Где подсматривать идеи (для человека, агенту сеть закрыта)

- Awwwards, CSS Design Awards, The FWA, Orpetron — премии, сайты дня.
- Godly — лента эффектных сайтов с видео-превью.
- Land-book, Lapa Ninja, One Page Love — галереи лендингов по нишам.
- Dark Mode Design — только тёмные сайты.
- Codrops — демо эффектов с разбором.

Скриншот понравившегося сайта можно приложить к брифу в Landly: агент возьмёт
с него визуальный язык, но не тексты и не структуру один в один.
