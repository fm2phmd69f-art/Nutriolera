# Первый экран: не шаблон

Первый экран — самое характерное, что есть в предмете брифа, в самой подходящей форме.
Типовой SaaS-hero — плашка над заголовком, заголовок, подзаголовок, две кнопки и
строка из трёх цифр — это не выбор, а привычка. Бери его только если бриф прямо
о нём просит.

## Сначала выбери архетип — по предмету, а не по привычке

| Архетип | Что на экране | Когда |
|---|---|---|
| **Плакат-вордмарк** | Название огромным шрифтом во всю ширину, один предмет-образ в пустоте | Сильное имя, бренд с характером |
| **Объект-экспонат** | Один крупный предмет (продукт, процедурный арт-объект) по центру, текст мелко по краям | Физический продукт, метафора в названии |
| **Процедурный образ** | Сгенерированная графика на весь экран (пряди, потоки, рельеф), текст поверх с маской | Абстрактные сервисы: VPN, ИИ, данные, финансы |
| **Фото на весь экран** | Кинематографичный кадр, текст в углу, минимум элементов | Места, еда, люди, путешествия, события |
| **Редакционный разворот** | Колонки как в журнале: крупная антиква, подпись, фото, номер выпуска | Эксперты, авторы, мода, культура |
| **Живое демо** | Работающий кусок интерфейса: печатается запрос, считается результат | Сервисы, где ценность видна в действии |
| **Типографика** | Только слова: гигантский акцидентный набор, игра размеров и начертаний | Смелые бренды, агентства, манифесты |
| **Сцена-коллаж** | Предметы, стикеры, фото внахлёст под углами | Детское, ремёсла, локальный бизнес, фестивали |
| **Карта или схема** | Маршрут, план, диаграмма как главный образ | Логистика, туризм, недвижимость, обучение |

Две похожие страницы подряд не должны получить один архетип и одну компоновку.

## Живой элемент — обязательно

В первом экране должен быть один главный живой элемент: процедурная графика
(guides/procedural.md), эффект из библиотеки анимаций (если она доступна) или
осмысленная анимация появления. Один — не три: одна сильная деталь лучше набора.

## Чего не делать

- плашку-«бейдж» над заголовком по умолчанию;
- две кнопки рядом, если второе действие ничего не даёт;
- строку «42 страны · 5 устройств · 900 Мбит/с» под кнопками по привычке;
- градиентное пятно на фоне «для красоты»;
- выделять одно слово заголовка цветом или курсивом без смысла;
- центровать всё подряд: выравнивание — решение, а не значение по умолчанию.

## Проверка

Закрой глазами логотип. Если этот первый экран можно подставить другому продукту той
же категории и никто не заметит — он шаблонный. Переделай.
