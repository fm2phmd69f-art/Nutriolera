# Иконки и эмодзи

Рисовать иконки вручную не нужно: рядом лежит библиотека, около 33 тысяч
готовых иконок в 18 файлах. Одна иконка — одна строка:

```
имя | теги | <svg …>…</svg>
```

## Как найти иконку

Ищи через Grep в одном файле набора, английскими словами:

- по имени: шаблон `^wallet ` в `library/icons/lucide.txt`;
- по смыслу: шаблон `money|payment` с `-i` — совпадёт и с тегами;
- смотри 3–5 вариантов (`head_limit`), а не всю выдачу: строки длинные.

SVG из строки вставляй в страницу как есть. Размер задаёт CSS
(`width`/`height` или `font-size` с `width:1em;height:1em`), а цвет —
`color` у родителя: иконки рисуются через `currentColor`.

## Наборы

Один набор и одно начертание на всю страницу. Иконки из разных файлов
на одной странице не смешивай: у них разная толщина линии и геометрия.

| Файл | Характер | Подходит |
|---|---|---|
| `lucide.txt` | ровная линия 2px, скругления | почти везде, SaaS, сервисы |
| `tabler.txt` | линия 2px, самый большой выбор (5 тыс.), есть бренды: `brand-telegram`, `brand-vk`, `brand-whatsapp` | когда нужно что-то редкое |
| `tabler-filled.txt` | заливка к tabler | активные состояния, акценты |
| `phosphor-regular.txt` | мягкая линия, дружелюбная | потребительские продукты, еда, дети |
| `phosphor-thin.txt`, `phosphor-light.txt` | тонкая линия | премиум, мода, косметика, архитектура |
| `phosphor-bold.txt` | толстая линия | плакатные, спортивные, игровые страницы |
| `phosphor-fill.txt` | заливка | крупные иконки-акценты |
| `phosphor-duotone.txt` | заливка плюс полупрозрачный второй слой | тёплые, иллюстративные страницы |
| `mingcute-line.txt`, `mingcute-fill.txt` | округлая, мягкая, «приложение» | мобильные приложения, доставка, сервисы |
| `remix-line.txt`, `remix-fill.txt` | нейтральная, строгая | бизнес, B2B, финансы |
| `hugeicons.txt` | линия 1.5px, современная (6 тыс.) | ИИ, технологии, стартапы |
| `iconoir.txt` | тонкая линия 1.5px, геометричная | дизайн, архитектура, редакционные страницы |
| `heroicons-outline.txt`, `heroicons-solid.txt` | классическая UI-иконка, мало вариантов | интерфейсные детали |
| `fluent-emoji.txt` | цветные плоские эмодзи (3 тыс.) | дружелюбный тон, детям, еда, события |

Эмодзи из `fluent-emoji.txt` — цветные SVG по 2–5 КБ. Их можно ставить
рядом с иконками любого набора, но не больше 6–8 на страницу: следи за
весом файла.

## Правила

- Иконка поддерживает смысл, а не украшает. Ставь её в списках преимуществ,
  шагах, контактах, характеристиках. На каждом заголовке иконка не нужна.
- Размер иконки согласуй с кеглем соседнего текста: обычно это 1–1.25em
  рядом с текстом и 32–48px в крупных карточках.
- Толщину линии можно менять атрибутом `stroke-width` у корневого `<g>`
  или `<path>`, если странице нужна линия тоньше или толще.
- Декоративной иконке оставь `aria-hidden="true"`. У иконки-кнопки без
  текста нужна `aria-label` на кнопке.
- Логотипы реальных компаний из брендовых иконок ставь только по смыслу:
  «мы в Telegram», способы оплаты. Выдумывать клиентов и партнёров из них нельзя.
