# Готовые элементы интерфейса

128 элементов, отобранных вручную из открытой коллекции Uiverse.io (лицензия MIT,
текст — в LICENSE-uiverse.txt): кнопки с характером, переключатели, выбор тарифа,
поля, подсказки, карточки и CSS-узоры для фона. Каждый — отдельный файл
`library/ui/<папка>/<имя>.html`: разметка и `<style>`.

## Как использовать

1. Выбери по таблице 1–3 элемента, которые подходят продукту и стилю страницы.
   Это акценты, а не набор на каждый блок: главная кнопка, переключатель
   «месяц / год», узор под один блок.
2. Открой файл через Read и перенеси разметку и стили целиком. Классы уже
   с префиксом `uv-имя-`, поэтому не пересекаются со стилями страницы.
   Обёртку `<div class="uv-…" style="display:contents">` не удаляй: к ней
   привязаны стили.
3. **Переделай под страницу:** надписи — на русском и по смыслу брифа
   («Hover me» → «Записаться»), цвета — из палитры, шрифт — шрифт страницы
   (в оригинале бывают Montserrat, Poppins и другие неподключённые шрифты).
   Кнопку-ссылку делай `<a href>`, если она никуда не отправляет форму.
4. Оставь комментарий `/* From Uiverse.io by … MIT License */` в стилях — это
   условие лицензии.
5. Проверь фокус с клавиатуры (`:focus-visible`) и ширину 375px: часть
   элементов задана в пикселях.

Элементы с анимацией уважают тариф и меру так же, как эффекты из effects.md:
не больше одного громкого на страницу.
